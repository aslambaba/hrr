About the Project

The Handwritten Digit Recognizer is a Machine Learning–based web application designed to identify handwritten numerical digits from user-drawn input or image data. The system is trained using the popular MNIST dataset, which contains thousands of labeled digit images.

This project demonstrates the practical use of Pattern Recognition, Image Processing, and supervised learning algorithms such as KNN and SVM.

Key Features

Upload Digit Image

Users can upload digits images directly using an interactive upload field.

Machine Learning

Uses trained ML models to predict digits accurately.

Web Based

Fully responsive web application built using Django.

How It Works

  1. User upload digits images by using upload file fields.
  2. The image is preprocessed (resizing, normalization).
  3. The trained ML model analyzes the digit.
  4. The system predicts and displays the result.
